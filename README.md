# Kanoski-Lab-HPCd-DA-manuscript-code
This is MATLAB_R2022b code pertaining to the analysis of fiber photometry data conducted for the HPCd DA manuscript
Installation time for MATLAB_R2022b with all statistical, linear algebra, and plotting packages on a standard i7 intel CPU chip with 8GB of RAM is approximately ~30-45 minutes.
Signal_Confirmation_ZB is the MATLAB script that performs the analysis of raw photometry files for the pharmacology-based signal confirmation of GRAB_DA signal. It performs the isosbestic signal subtraction and correction and AUC quantification of pre injection vs post injection.
Neurophotometrics_ZB.m is the MATLAB script that performs the primary analysis of raw photometry files, it performs the isosbestic signal subtraction and correction.
Refeeding_meal_bout_analysis.m is the script that performs the quantification of changes in DA binding within active eating bouts interbout intervals and extracts data to perform AUC quantification on pre consumption and post consumption periods.
